# Privacy Policy

Instant Daily Memo stores diary text in the user's Google Calendar through Android's Calendar Provider.

## Data Collected

The app does not collect, transmit, sell, or share user data with the developer or third parties.

## Calendar Access

The app requests calendar read and write permissions to:

- read the memo event for the selected day;
- create or update an all-day event named `memo`;
- let the user choose the destination Google Calendar.

Diary text is saved only in the calendar selected by the user.

## Network

The app does not access the network directly.

## Contact

Contact information should be added before publishing on Google Play.
