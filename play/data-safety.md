# Google Play Data Safety Notes

Use these notes when completing Play Console's Data Safety form.

- Data collected by the developer: No.
- Data shared with third parties by the developer: No.
- Data processed on device: Yes.
- User-created content: Diary text is written to the user's selected Google Calendar through Android Calendar Provider.
- Calendar permission purpose: App functionality.
- Network access by this app: None.
- Account creation: Not supported.
- Ads: None.
- Analytics: None.
- Crash reporting SDKs: None.

The user should review this against the final Play Console wording before submission.
