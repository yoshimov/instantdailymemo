# Instant Daily Memo

## Short Description

A fast diary memo app that saves to Google Calendar.

## Full Description

Instant Daily Memo is a small app for writing today's diary or memo as quickly as possible.

The editor opens immediately. Your text is saved to the description field of a Google Calendar event named `memo`. If today's `memo` event already exists, the app loads it so you can continue writing.

Features:

- Opens directly to the memo editor
- Saves to a Google Calendar event named `memo`
- Loads an existing memo for today
- Lets you choose the destination calendar
- Includes save and close buttons
- Opens the calendar app when you tap the date
