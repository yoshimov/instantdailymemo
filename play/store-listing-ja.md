# Instant Daily Memo

## Short Description

起動してすぐ書ける、Google Calendar 保存の日記メモ。

## Full Description

Instant Daily Memo は、すばやく今日の日記やメモを書き残すための小さなアプリです。

起動するとすぐ入力画面が開き、内容は Google Calendar の `memo` 予定のメモ欄に保存されます。既に今日の `memo` 予定がある場合は、その内容を読み込んで続きから書けます。

主な機能:

- 起動直後に入力欄を表示
- Google Calendar の `memo` 予定に保存
- 既存のメモを読み込み
- 保存先カレンダーを選択可能
- 他のアプリから共有されたテキストを追加
- 音声入力に対応
- 保存・終了ボタン
- 日付タップでカレンダーアプリを表示
